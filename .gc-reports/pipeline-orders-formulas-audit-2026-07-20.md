# Orders and formulas pipeline audit — 2026-07-20

## Mandate and safety boundary

Audit the complete maintenance execution chain:

```text
order trigger
→ formula or exec selection
→ repository/worktree/branch/SHA binding
→ claim and routing
→ tests and review
→ request_changes fix loop
→ exact-SHA re-review
→ external-action gate
→ completion and re-entry
```

This pass is internal and fail-closed. It does not authorize pushes, PR
creation, reviews/comments, merges, auto-merge, destructive cleanup, broad
restarts, or pool expansion.
