DESCRIPTION

  Source: external CodeScaleBench Verification Report received 2026-04-24.    
  Audit of 25 CSB tasks (18 SDLC + 7 Org) found 16% usable as-is, 88% usable  
  after fixes, 12% broken. Defect classes generalize to EB and codeprobe.     
                                                                              
  ## Five defect classes (each with bright-line rule)                         
                                                                              
  A. Oracle-instruction coherence — every oracle path/symbol exists; lang/path
  constraints match                                                           
  B. Verifier mechanical correctness — set -euo pipefail, no grep|head,       
  shellcheck clean                                                            
  C. Calibration triad — null ≤0.1, golden ≥0.9, adversarial-keyword-dump ≤0.5
  (highest-leverage check)                                                    
  D. Scoring-method honesty — declared scoring_method tier; checklist +       
  secondary judge required                                                    
  E. Agent-agnostic fairness — no oracle paths in CLAUDE.md/AGENTS.md/READMEs 
                                                                              
  ## Architecture                                                             
                                                                              
  • benchmark_qa_core: shared Python lib (~300 lines, schema-agnostic). Pure  
  functions: (instruction, oracle, repo_path, aux_files) → findings. Houses   
  A/D/E logic.                                                                
  • Per-rig adapters: thin wrappers feeding native task shape into the lib.   
  • B/C stay per-benchmark (they touch the verifier runtime, not just static  
  schema).                                                                    
                                                                              
  ## Already in flight (this session)                                         
                                                                              
  • codeprobe-zat9 (CLOSED): multi-backend oracle curator — covers class A for
  symbol-reference-trace mining                                               
  • codeprobe-voxa (in_progress): reward vs IR diagnostics separation — covers
  class D for codeprobe                                                       
  • EnterpriseBench-0rv.25 (CLOSED today): point-fix for 4 EB ground-truth    
  bugs (not the structural framework)                                         
                                                                              
  ## Decision (sjarmak 2026-04-29)

  **upstream push**, not the public corpus's existence.

  EPIC ACCEPTANCE TIGHTENED 2026-04-30 (sjarmak feedback).                    
                                                                              
  The original acceptance ('benchmark_qa_core lib lands, calibration triad    
  runs, verifier-lint clean') was static-schema-checks scope. After auditing  
  codeprobe's voxa close (recall-only reward) against CSB's                   
  docs/SCORING_SEMANTICS.md, the actual gap is broader: all 3 rigs need a     
  unified ScoreResult contract that lets cross-rig comparison and tooling-    
  decision plots be meaningful.                                               
                                                                              
  ## Unified contract (all 3 rigs emit this)                                  
                                                                              
    {                                                                         
      "reward":          float,    // task completion quality, verifier-      
  defined, [0..1]                                                             
      "scorer_family":   string,   // rubric used — for interpretability      
      "sub_scores":      {...},    // rubric breakdown                        
      "diagnostics": {                                                        
        "task_time_seconds": float,                                           
        "token_cost_usd":    float,                                           
        "ir_metrics":        { "precision": ..., "recall": ..., "f1": ... }   
      }                                                                       
    }                                                                         
                                                                              
  Drops CSB's pass_threshold/passed/scorable ceremony. Goal isn't policy      
  compliance; goal is HIGH-SIGNAL REWARD for tooling-decision-making (does MCP
  help? which agent? at what cost?).
