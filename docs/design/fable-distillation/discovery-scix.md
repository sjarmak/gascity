## 1. Project shape

SciX Experiments is a **research-infrastructure project** (Python 3.11+) that turns the full NASA ADS / SciX corpus — **32.4M papers, 299.3M citation edges** (1800–2026) — into an **agent-navigable knowledge layer** exposed through a **15-tool MCP server**. Its thesis (README, `docs/paper_outline.md`, ADASS-track paper): instead of ranked lists, expose the _structural topology of science_ — hybrid retrieval, the citation graph, research communities, and a cross-discipline entity graph — so AI agents can navigate the literature programmatically. It is a **live retrieval system with a publication track**, not a benchmark (contrast EnterpriseBench).

- **Architecture is a dual store.** PostgreSQL 16 + pgvector 0.8.2 holds papers/metadata/citations/entities/communities and both BM25 lexical lanes; **Qdrant 1.17/1.18 (local NVMe) serves the INDUS dense lane** (`scix_indus_v2_papers_s1`) per ADR-013. The README's "Single PostgreSQL instance … No separate search engine" is **stale** — Qdrant is now a second stateful system (see §3 doc-drift).
- **Retrieval is a ~3-signal RRF** (`RRF_K = 60`, `src/scix/search.py:34`): title/abstract tsvector BM25 + body BM25 (~46% coverage) + INDUS 768d dense (via Qdrant); optional entity-alias lexical lanes off by default; optional post-fusion reranker. The retired OpenAI/`text-embedding-3-large` dense lane is **removed** from live code (commit 8b9cc90, bead 7gb4).
- **The differentiated surface** beyond search: citation-graph analytics (PageRank/HITS/Leiden communities), a **cross-discipline entity graph** (~57.7M paper-entity links, 13 entity types, GLiNER NER), and **provenance tools** (`claim_blame` traces a claim to its earliest non-retracted origin; `find_replications`). These are what the ADASS paper claims Elicit/SciSpace/paper-qa do not offer.
- **Who runs it:** effectively a **solo maintainer (Stephanie / sjarmak, 50 of 50 sampled committers, 706 commits) plus a Gas City agent fleet.** A `scix-experiments-pl` PL runs weekly deep-audits; a `scix-worker` pool executes bead-tagged branch work (`GC_AGENT` env → autonomous, `bd close`, `gc mail mayor` on block). The "retiring fellow" here is the accumulated **retrieval/storage/scoring discipline** held across ~16 ADRs, ~30 PRDs, the `.gc-reports` audits, and the bead store — not in a readable git history (see §3).
- **Docs of record:** ADRs (`docs/ADR/006`–`016`), PRDs (`docs/prd/`, ~30), premortems (`docs/premortem/` + `docs/prd/premortem_*`), `docs/paper_outline.md` (ADASS), `docs/mcp_tool_audit_2026-{04,06}.md`, `docs/PARITY_PLAYBOOK.md`, `docs/DEPLOYMENT.md`, runbooks (`docs/runbooks/` + loose `runbook_*.md`). **`docs/conventions/` is referenced by CLAUDE.md's compass table but does not exist** — a live doc-drift bug (the compasses point at absent playbooks).

## 2. Build / test / CI reality

**One CI workflow** (`.github/workflows/check.yml`), Python 3.11, a `pgvector/pgvector:pg16` service DB (`scix_test`) loaded from `ci/scix_test_schema.sql`. The gate is **`make check-ci`** = `lint-changed` + `fmt-check-changed` (ruff 0.15.8 + black 25.1.0, **scoped to files changed vs `origin/main`** because the tree carries pre-existing format debt) + **the full pytest suite** under `PYTEST_ARGS='-m "not integration and not network"'`. Install is `pip install -e '.[dev,qdrant,graph,mcp]'` — heavy model/viz deps (torch, umap, fastapi, leidenalg) are **intentionally not installed**, and their test modules self-skip via `tests/conftest.py`.

**Verified traps for a Sonnet-class newcomer:**

1. **The default DSN is production.** `SCIX_DSN` unset → `dbname=scix` = the 32M-paper prod DB (`src/scix/db.py:16`). Write/delete tests skip **silently** unless `SCIX_TEST_DSN` is set and non-prod (`is_production_dsn` returns `False` for empty/None — resolve the fallback before calling). Running `pytest tests/` without `export SCIX_TEST_DSN="dbname=scix_test"` looks green but silently deselects the destructive suite.
2. **Local `make check` ≠ CI `make check-ci`.** `make check` lints/format-checks the **whole tree** (all markers, all debt); CI scopes lint/fmt to changed files and applies the marker filter. A branch can pass one and fail the other.
3. **Optional-dep collection guards.** `tests/conftest.py` populates `collect_ignore` via `importlib.util.find_spec` (`_OPTIONAL_DEP_MODULES`): missing `fastapi` skips 12 viz modules; missing `torch`/`leidenalg`/`umap`/`defusedxml` skip their modules; some modules use in-file `pytest.importorskip`. CI installs `qdrant/graph/mcp` but not the heavy set, so those self-skip cleanly (the goal of bead o835 "CI green-up"). A dependency-free sandbox loses whole test modules without erroring.
4. **The MCP contract drift gate.** `tests/test_mcp_contract_conformance.py` asserts `contract/scix_mcp_v1.json == build_contract()`; any tool add/change/rename without `python scripts/gen_mcp_contract.py` fails CI. Adding a **16th visible tool** trips an **import-time `RuntimeError`** (`src/scix/mcp_server.py:631`) so the server won't even boot. A breaking change bumps `CONTRACT_VERSION` ("1", `src/scix/mcp_contract.py:32`) → new `scix_mcp_v2.json`.
5. **No lint/type gate on the full tree, no mypy in CI** despite `.mypy_cache/`/`.ruff_cache/` on disk — those are developer-local. `E501` is owned by black, `E402` is ignored under `scripts/`/`tests/` (intentional post-`sys.path` imports).
6. **Heavy work MUST run under `scix-batch`** or CI-adjacent scripts OOM-kill the co-hosted gascity supervisor (§6). This is a build/run-environment fact, not just an ops nicety.

## 3. Git archaeology — lessons that would die with the fellow

**The visible git history is shallow and misleading.** `git rev-list --count HEAD` = **706 commits, but the earliest reachable commit is 2026-06-11** and the latest 2026-06-30 (~37 commits/day = agent-fleet velocity). That start date **postdates** the CHANGELOG's `v0.1.0` (2026-04-20) and the ADR/migration sequence, so the repo was **re-inited / history-truncated around 2026-06-11**. Pre-06-11 decisions survive **only in ADR/PRD/bead prose**, never in commits. There are **no `git revert` commits** (back-outs are recorded in bead threads, and `rtk` truncates `git log` anyway). **Archaeology path here = ADRs + PRDs + `.gc-reports` audits + the bead store, not git.**

The dominant lessons, each with its artifact:

- **The pgvectorscale DiskANN catastrophe (bead 12rp, closed; ADR-013).** `paper_embeddings.embedding` was a _dimensionless_ `vector` column (multi-model table); DiskANN needs a fixed dim, so the rebuild DDL cast `(embedding)::vector(768)` into a **true expression index that pgvectorscale cannot scan** (`assertion failed: attnum > 0`). Prod built `vector_cosine_ops` (float32) while the _validated_ benchmark used `halfvec_cosine_ops` — the go/no-go numbers described a config prod never ran. The serving HNSW was dropped **before** the replacement was validated → **~2 weeks lexical-only, a 56h build lost 2026-06-11.** This bought the four **"don't trust a new index" rules** (ADR-013:89–100, mirrored in CLAUDE.md): ≤50k-row scratch build + forced-index-scan smoke test before any multi-hour build; benchmark DDL **byte-identical** to prod DDL; never drop a serving index before its replacement is validated scannable; re-examine architecture pins when they start selecting immature components. Outcome: the dense lane moved to **Qdrant** (ADR-013).
- **The `paper_embeddings` out-of-process `DROP TABLE` (bead s7cy, OPEN — the live fire).** ADR-015 authorized dropping the two INDUS **indexes** (Stage 1, migration 071), soak-gated to 2026-07-11. Instead a full `DROP TABLE paper_embeddings` (+ `embedding_outbox`) was executed **out-of-process ~2026-06-29/30, with no NAS archive**. Consequence: `daily_sync.sh` aborts at Step 5 every run since (also skipping the `v_claim_edges` MV refresh and outbox drain); **~83K new papers have no dense vector** in Qdrant; `schema_migrations` tops out at 68 (069–072 applied by hand, unrecorded — there is **no auto-migration runner**). The fix (direct-to-Qdrant embed via new `src/scix/qdrant_dense.py` + `migrations/072_indus_qdrant_synced.sql` + a `indus_qdrant_synced` watermark table) is **implemented but sitting UNCOMMITTED in the working tree** — committed HEAD `embed.py` still targets the dropped table, and `scripts/embed_fast.py` is still broken. **A newcomer reading committed HEAD sees a pipeline that cannot run.**
- **The payload-preservation hazard (bead e4xv, closed).** A bibcode-only Qdrant upsert _wipes_ the ADR-008 filter payload on re-embed. Fixed once (full-payload re-ingest via `src/scix/qdrant_payload.py`); the new uncommitted `qdrant_dense.py::upsert_dense` **re-introduces the same bibcode-only pattern** with a docstring warning — a recovery re-upsert would strip enrichment.
- **The storage/capacity crisis (epics puln, woib; ADR-016).** Prod NVMe repeatedly hit 98–99% (1.2T scix PG is the whale; swap exhausted). The **entire dense-lane flip, entity ingests, and reclamation are parked on ONE operator action** — a scheduled maintenance window to free disk and pin ~25GB dense-lane RAM. The audit's `BLOCKED_CHECK` is **RED (blocked on human)**. ADR-016 (accepted) seals `papers_fulltext` (493GB) to a per-year read-only NAS cold tier for ≤2024, reclaiming ~470–493GB; body-BM25 Phases 2&3 were **cancelled** (A3) because body text is actively used and a stored `body_tsv` would be _larger_ than raw body.
- **The parting architectural bets:** the **15-tool MCP consolidation** (30→13→15, triple-enforced cap, bead 9afa; the alias-routing single-source-of-truth after a 24-branch if-chain drifted); the **cross-discipline entity expansion** (dbl epic, GLiNER NER beyond astrophysics); **provenance/claim tooling** (`claim_blame`); and the **honest retrieval-quality finding** below.
- **The uncomfortable retrieval result (beads isve, 9sv1):** on the 1200q recall gold set, `dense_only` nDCG@10 (**0.3803**) is _below_ `bm25_only` (**0.4291**) — **the INDUS dense lane underperforms BM25 alone.** `naive_rrf(k=60)` still lifts +0.098 over dense-alone, but the sweep explicitly notes the lift **partly reflects outrunning a weak dense lane, not a clean fusion gain.** This is the paper's central credibility question (see §7 skill 14).

## 6. Knowledge gaps a Sonnet-class newcomer falls into

Ranked by expected damage:

1. **Running heavy work in the default shell cgroup instead of `scix-batch`.** This host **also runs the gascity supervisor**; `user@1000.service` has `ManagedOOMMemoryPressure=kill` at 50%, so an unwrapped multi-GB/>1-min script pushes the user slice into pressure and **oomd kills the supervisor** (taking down mayor + every worker). Fix: `scix-batch <cmd>` (transient `systemd-run --scope`, `MemoryHigh=20G`/`MemoryMax=30G`/`ManagedOOMPreference=avoid`; override `--mem-high/--mem-max`). Two self-enforcement guards exist and use **different markers**: `--require-batch-scope` checks `SYSTEMD_SCOPE`; `--allow-prod` checks `is_production_dsn` **and** `INVOCATION_ID` (auto-set by `systemd-run`). Latent gotcha: the wrapper sets `INVOCATION_ID` but not `SYSTEMD_SCOPE`, so `--require-batch-scope` relies on `SYSTEMD_SCOPE` being present in the invocation env.
2. **Treating the default DSN as safe.** `SCIX_DSN` unset = prod `scix`. Any write without `SCIX_TEST_DSN` (or `--allow-prod` discipline) targets 32M live papers.
3. **Trusting stale docs.** README ("no separate search engine"), CHANGELOG ("pgvector HNSW dense", 13 tools), CLAUDE.md header ("over PostgreSQL 16 + pgvector"), and the `scix-mcp` skill (OpenAI lane, trycloudflare) all describe a **pre-Qdrant, pre-consolidation** world. Trust ADRs + code + beads; the compass table even points at a `docs/conventions/` dir that doesn't exist.
4. **Editing the committed embed path believing it runs.** Committed `embed.py` / `embed_fast.py` target the **dropped** `paper_embeddings` table; the working path is the **uncommitted** direct-to-Qdrant fix (bead s7cy). Verify working-tree + bead state before touching ingest.
5. **The query_log telemetry trap.** Guard-blocked / structured-error requests log `success=TRUE` (because `_dispatch_tool` returns error JSON without raising). `WHERE success=FALSE AND error_msg IS NOT NULL` silently drops them; use `WHERE success=FALSE OR error_msg IS NOT NULL`.
6. **Violating the "don't trust a new index" discipline** (50k scratch + forced-index-scan + byte-identical DDL) — the 56h/2-week failure that bought it.
7. **Touching an ADR-pinned axis casually:** dense lane serves from **Qdrant not pgvector/pgvectorscale**; **768d locked**; **halfvec (float16) safe, binary quantization banned** (>40% nDCG@10 loss); **no paid-API embedding lane**; Qdrant/PG data dirs **never on NAS**. Each is an ADR/`feedback_*` decision, not a preference.
8. **Adding a 16th visible MCP tool** (import-time `RuntimeError`) or changing the tool surface without `gen_mcp_contract.py` (contract drift gate). The 15-cap is premortem-driven (agent selection accuracy).
9. **Removing the body-AI OA gate.** Body-AI scripts (`run_ner_bodies.py`, `extract_citation_contexts.py`, `section_pipeline`, `run_chunk_pass.py`) must gate on `papers_is_oa_or_preprint` — publisher TDM-clause (Wiley/Springer) risk. Abstract-only AI is universally indexable.
10. **Re-doing the ZFC heuristic mistake** — semantic entity-type classification belongs in the entity graph, not a keyword table in orchestration code (the `_guess_entity_type` violation, since fixed, bead aptn).
11. **Overstating NER precision.** The dbl.3 profile's "≥80% at conf≥0.7" is **not met in aggregate**; precision is per-`(type, era, agreement)` bucket (dataset pre-1990 ~0.00–0.09). When the bucket is unknown, use the **lower** bound.
