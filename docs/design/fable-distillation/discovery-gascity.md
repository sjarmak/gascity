## 1. Project shape

Gas City is an **orchestration-builder SDK** in Go: it extracts Gas Town's reusable infrastructure (runtime providers, work routing, formulas, orders, health patrol, declarative city config) into a toolkit where **all role behavior is user config and the Go code contains zero hardcoded roles**. The inversion everything hangs off: _work is the primitive, not orchestration_. The MEOW stack (beads → molecules → formulas) is the load-bearing layer; Gas Town's mayor/deacon/polecat/witness roles exist only in config and prompts, never in Go.

- **Binaries:** `cmd/gc` (CLI + controller daemon, ~95% of the surface, ~200 non-test files), plus three codegen tools (`genschema`, `genspec`, `gen-client`).
- **Core seams:** `runtime.Provider` (internal/runtime/runtime.go — tmux/subprocess/exec/k8s/fake; transport only), `beads.Store` (internal/beads/beads.go — prod `BdStore` shells out to the `bd` CLI backed by an embedded **Dolt SQL server**), `events.Provider` (append-only JSONL, typed payload registry in internal/events/payload.go), `internal/config` (TOML compose/patch/override; config _presence_ is the feature-flag system, capability Levels 0–8).
- **Runtime model:** a per-city controller loop — single `select` over ticker + size-1 non-blocking poke channels (dropped pokes are intentional debounce), cmd/gc/city_runtime.go:547-580. Each tick runs order dispatch _before_ session reconcile (city_runtime.go:733-735). The reconciler drives sessions toward a computed desired state (cmd/gc/session_reconciler.go, build_desired_state.go). Reliability doctrine is NDI (nondeterministic idempotence): sessions are disposable, beads/hooks/molecules durable, no PID/status files ever — liveness comes from the live process table.
- **Contributor contract:** AGENTS.md (19.8K) is the constitution — ZFC (Go moves bytes, models decide), Bitter Lesson test (every primitive must get MORE useful as models improve — this is why the SDK deliberately has no skills system, no capability flags, no MCP registration), GUPP, SDK self-sufficiency (everything must work with only the controller running), object model at the center (CLI/API are projections), typed wire + typed events (CI-enforced via `TestEveryKnownEventTypeHasRegisteredPayload` and spec drift gates).
- **Docs:** engdocs/architecture/ (nine-concepts.md, glossary.md, per-primitive specs), engdocs/contributors/ (codebase-map, primitive-test, huma-usage, reconciler-debugging), engdocs/design/ (deep design docs), docs/ (user-facing Mintlify, generated reference). Doc rule: tutorials/DX win over architecture docs.

## 2. Build / test / CI reality

Everyday gates: `make setup` once, then `make build && make check` (fmt+lint+vet+fast unit). `make check-docs` for docs. `make dashboard-check` for API/dashboard changes.

**Verified traps for a Sonnet-class newcomer:**

1. `make test` runs under `env -i` with an allowlist (Makefile TEST_ENV, lines ~175-221) — shell exports are invisible; use `EXTRA_TEST_ENV=`.
2. `GC_FAST_UNIT=1` routes the slow cmd/gc process suite (20–25m) out of `make test` — "tests pass" locally ≠ green CI.
3. Whole tiers hide behind build tags: `integration`, `acceptance_a/b/c`, `chaos_dolt`. `go test ./...` silently skips them.
4. Real daemons needed: dolt server (bdstore), `bd` CLI, tmux, authed claude/codex/gemini CLIs (acceptance-C, worker inference).
5. **Never `tmux kill-server`** — tests use `gctest-<8hex>` prefix + tmuxtest.Guard; target the city/test socket only.
6. No `-race` tier in the standard gates.
7. Generated-artifact drift is a hard CI gate (`spec-ci`, `dashboard-ci`); the pre-commit hook regenerates only if go/npm tooling is on PATH.
8. `tsc --noEmit` is load-bearing — Vite build ignores type errors.
9. Pre-_push_ (not pre-commit) runs tests (`make test-fast-parallel`, LOCAL_TEST_JOBS=3), and only when *.go changed.
10. `ci-required` is the real branch-protection check; `cmd-gc-process`/`pack-gate`/`docker-session`/`k8s-session` may be `skipped` (path-gated), everything else must be green.
11. CI hardcodes `DOLT_VERSION: 1.86.6` while deps.env pins 1.88.0 — CI does not source deps.env (only `make docker-base` does).
12. Long timeouts are normal: cmd/gc process 25m, integration 30m, acceptance-C 45m, tutorial goldens 90m.

Test doctrine (TESTING.md): five kinds — unit (testify, next to code), testscript (`.txtar` under cmd/gc/testdata/, real `gc` binary, doubles as tutorial regression; fakes default via GC_SESSION=fake/GC_BEADS=file/GC_DOLT=skip), integration (tag-gated, real tmux/fs), docsync (`make check-docs`), coordination (exec-spy `GC_BEADS=exec:<script>`). Hand-written fakes only, no mock libraries; conformance suites run one contract across all implementations of Store/Provider/Recorder/Mail.

Release: version lives only in the git tag (`var version = "dev"`); `scripts/bump-version.sh` → release.yml → GoReleaser + SBOM + attestation + Homebrew tap. `rc-gate.yml` is the manual RC superset (incl. 90-min tutorial goldens). In-repo `release-gates/` holds 20 per-blocker gate files. CI runner policy: trusted authors get Blacksmith runners (.github/workflows/scripts/runner_policy.py).
